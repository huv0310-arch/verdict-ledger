# 《丛_纪念章规格》引用位

- **正本不入库**：规格正本保存在发布人本机的私有目录（不入库的沙箱/正本区），本仓库只留这个引用位。
- **红线**：开源门槛跑满前，正本内容不外发、不复制进本库、不进公告。
- **什么时候搬进来**：四门槛全勾 + 发布人确认后，才把正本按 `docs/纪念章规格.md` 落一份，
  落之前过一遍去业务扫描（`python ci/run_ci.py` 里的那步）。
- **引用写法**：发布说明或致谢需要提纪念章口径时，只写「见仓库 docs/纪念章规格.md」，
  在正本入库前则写「规格由发布人保管，按需索取」。

## 版本钉扎（2026-11-06 补：外部 fork 与 bug 修复是否影响章面，确认不影响）

- **章钉在发布 tag 上**（v3.2 @ 实际发布 commit，日期以 tag 落点为准）：代码后续怎么迭代、别人 fork 怎么改，**章面内容与发放记录不动一个字**
- 章记的是「最早看见并参与的人」，不是「代码当时的完美程度」——被提 bug、被 fork、被 PR 均不影响发放
- 开源后外部贡献（首个 issue / 首个 PR / 首个可复核复现）**可作为章的加注素材**，追加不覆盖
