## 0 数据面：三份文件 + 两个公式（三份文件不随包发布，获取方式见发布说明/另行发布）

| 文件 | 是什么 | 形状 |
| --- | --- | --- |
| `journal.jsonl` | 判决流水，一行一条 JSON | 每行 `{"t":"node","key":…,"node":{verdict, reason, ts, ctx_fp, cross_fp, nid, …}}` |
| `journal.jsonl.chain` | 影子链（外挂、随账追加） | 一行 `{"n":0 起行号,"h":64 位哈希}` |
| `chain_anchor.json` | 链头**外部**锚定快照 | `{"kind":"v2_chain_anchor","head_h":…,"tail_h":…,"lines":713,"chained":713,"ts":"2026-11-06 12:30:52"}` |

**公式 A —— 链哈希（链的最小单元）**

```
h(n) = sha256( h(n-1) + "|" + json.dumps(row_n, sort_keys=True, ensure_ascii=False, separators=(",",":")) )
h(-1) = ""        # 首行的前值是空串
```

`row_n` = `journal.jsonl` 第 n+1 行 parse 出来的对象（`json.dumps` 用排序键、无空格，**不含行尾换行**）。

**公式 B —— 原行 sha256（本文件所有 `sha256` 列）**

```
sha256( 第 n+1 行的原始字节 )     # 不含行尾换行符
```

**两条判据**

1. 链绿：逐行重算 `h(n)` 与 `chain[n].h` 相等。某行算不上 = 该行事后被改；链比账短 = 有行没链上/被截断；链比账长 = 有行被删。
2. 锚上：`chain[0].h == anchor.head_h` **且** `chain[anchor.lines-1].h == anchor.tail_h`。

**复算脚本（三文件放同目录，直接跑；三份文件的获取方式见发布说明/另行发布）**

```python
import json, hashlib
def H(prev, row):
    body = json.dumps(row, sort_keys=True, ensure_ascii=False, separators=(",", ":"))
    return hashlib.sha256((prev + "|" + body).encode("utf-8")).hexdigest()
rows  = [json.loads(x) for x in open("journal.jsonl", encoding="utf-8") if x.strip()]
chain = [json.loads(x) for x in open("journal.jsonl.chain", encoding="utf-8") if x.strip()]
prev = ""
for n, r in enumerate(rows):                      # 判据 1：链绿
    prev = H(prev, r)
    assert chain[n]["h"] == prev, "断链在第 %d 行" % n
a = json.load(open("chain_anchor.json", encoding="utf-8"))   # 锚点文件获取方式见发布说明（另行发布）
prev = ""
for n, r in enumerate(rows[:a["lines"]]):         # 判据 2：锚上
    prev = H(prev, r)
assert chain[0]["h"] == a["head_h"] and prev == a["tail_h"], "锚点对不上"
print("链绿", len(rows), "行；锚点头/尾均对上")
```
